📤 Publicar no Instagram

Conta

Conectar ou reconectar uma conta
  1. A conta do Instagram precisa ser Profissional (Criador ou Empresa) e estar ligada a uma Página do Facebook.
  2. Abra o Graph API Explorer, escolha o seu app e adicione as permissões: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement, business_management. Para ver os resultados e comentar sozinho, adicione também instagram_manage_insights e instagram_manage_comments.
  3. Clique em Generate Access Token, autorize, copie o token e cole aqui embaixo.
  4. ID e Chave secreta do app (no app da Meta: Configurações › Básico): com eles o token vira permanente. Ficam guardados neste PC, então só precisa preencher uma vez.
✓ ID e chave do app guardados: o token vira permanente sozinho.
